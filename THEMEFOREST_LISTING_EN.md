# ThemeForest Listing Draft — Gimmick (Telegram Mini App Marketplace)

## Product Name
**Gimmick — Telegram Mini App Digital Marketplace (React + FastAPI)**

## One-line Pitch
A production-ready Telegram Mini App template for selling digital products (game keys, in-game currency, accounts), with buyer/seller/admin roles, instant key delivery, disputes, notifications, and admin control panel.

---

## Product Description (ThemeForest-ready)
**Gimmick** is a full-stack Telegram Mini App marketplace template designed for digital goods businesses.
It combines a modern mobile-first frontend with a robust backend architecture so you can launch quickly and customize for your niche.

Built with **React + Vite + Tailwind** on the frontend and **FastAPI + SQLAlchemy** on the backend, Gimmick includes all core marketplace flows:
- Buyer checkout and instant delivery
- Seller listing and stock management
- Admin moderation and analytics
- Wallet, deposits, disputes, and notifications

This template is ideal for founders and teams who want a Telegram-native commerce product without building every marketplace component from scratch.

---

## Key Features

### Buyer Experience
- Product browsing and filtering
- Wallet-based checkout flow
- Instant digital key delivery
- Order tracking and status updates
- Built-in dispute flow and messaging
- Notification center (read/unread states)

### Seller Experience
- Seller subscription plans
- Seller dashboard and sales stats
- Product CRUD
- Key inventory upload/manage
- Withdrawal requests
- Optional featured seller promotion

### Admin Experience
- Full admin dashboard and KPIs
- User and seller management
- Role changes and impersonation
- Dispute resolution tools
- Deposit/withdraw moderation
- Branding controls (name/logo)
- Maintenance mode
- Broadcast announcements (audience groups + channels)

### Technical/Operational Features
- Role-based access control
- Access + refresh token auth
- Server-side token revocation
- Request ID tracing for debugging
- Security middleware and rate limiting
- Ready to run in dev and adaptable for production

## Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Zustand, Axios, Framer Motion
- **Backend:** FastAPI, SQLAlchemy (async), Pydantic, SlowAPI
- **Integrations:** Telegram WebApp, Telegram bot, crypto deposits (NowPayments flow)
